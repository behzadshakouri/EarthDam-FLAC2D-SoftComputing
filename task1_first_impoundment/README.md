# Task 1: first-impoundment study

Task 1 is a published component of the broader earth-dam research program.
This directory currently records its place in the multi-task framework; it
does not claim to provide a reproduction package.

The published title, authors, journal, year, DOI, data availability, and code
availability should be copied from the authoritative publication record before
the Task 1 release is tagged. They are deliberately not guessed here.

Task 1 materials can be added later without changing the archived Task 2
workflow.
