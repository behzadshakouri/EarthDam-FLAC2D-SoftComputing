# Original scripts manifest

The `legacy/original_task1_scripts` directory preserves the 70 MATLAB files
supplied by the author unchanged. They document the historical analysis and
figure-generation sequence, including intermediate revisions.

Canonical lineage starts with:

- `n19_outputs_gp_total_new.m`: output assembly;
- `n20_RVsRes_new.m`: QoI extraction;
- `n21`-`n24`: four response-model methods;
- `n12`-`n15`: four FoS methods;
- `n30`-`n35`: final paper figures.

Historical absolute Windows paths and intermediate WOA experiments are
retained only for provenance. They are not canonical runtime dependencies.
