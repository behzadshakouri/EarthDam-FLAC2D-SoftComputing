# Task 3 figure sources

`amin_cross_section_monitoring_grid.jpg` is the clean engineering redraw
supplied during author review. It is based on the Task 2 DWG and combines the
cross-section, material zoning, numerical grid, and water level. Its draft
marker layer contains extra and displaced points, so it is retained only as
an immutable visual source. `generate_task3_monitoring_response_figure.m`
removes that layer and reconstructs the authoritative ten-point arrangement
from the DWG: P10 at the crest; P6/P3/P9 at the upper level; P4/P2/P8 at the
middle level; and P5/P1/P7 at the base. The Task 3 output uses labeled teal
circles. The older reference PNG files remain preserved for provenance, and
the manuscript retains the adaptation citation.
