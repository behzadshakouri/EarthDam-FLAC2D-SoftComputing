# Reference results

This directory contains the completed fixed-split neuron-sensitivity metrics.
Every CSV contains 70 point-response cases: 67 modeled cases and the three
constant R5 targets at P8-P10.

Selected configurations are ELM-30, ELM-ABC-15, ELM-ACOR-15, and ELM-IGWO-5.
Raw FLAC2D histories and trained checkpoints are not redistributed. Re-running
the workflow with the complete private database regenerates checkpoints,
predictions, tables, and plots.
