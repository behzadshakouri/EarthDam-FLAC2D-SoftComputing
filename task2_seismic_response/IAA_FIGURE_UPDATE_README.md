# IAA Figure 3 repository update

Copy the included files into the same relative paths in the
`EarthDam-FLAC2D-SoftComputing` repository.

From MATLAB R2020a or newer, change to `task2_seismic_response` and run:

```matlab
files = generate_iaa_methodology_figures( ...
    'E:\path\to\IAA-20sec.xlsx',[], ...
    'InputUnits','g');
```

Generated files under `results/final_manuscript_figures/`:

- `a_PSA_heatmap.png` -- manuscript Figure 3(a)
- `b_PSV_heatmap.png` -- manuscript Figure 3(b)
- `IAA.png` -- separate IAA acceleration and PGA-envelope illustration
- `IAA_spectral_heatmap_data.mat` -- auditable plotted arrays and metadata

Use `'MakeIAAPlot',false` when only Figure 3 panels (a) and (b) are wanted.
The default damping ratio is 5%, the default period range is 0.05--2.0 s,
and the default one-column sampling interval is 0.01 s. Workbook columns can
be selected explicitly with `'TimeColumn',N` and `'AccelerationColumn',M`.

Important: provide the original signed IAA acceleration history. A monotonic
cumulative PGA envelope is not sufficient to calculate PSA or PSV, and the
script deliberately rejects such input. `IAA.png` is not Figure 3(c); the
current manuscript contains only the PSA and PSV panels in Figure 3.
