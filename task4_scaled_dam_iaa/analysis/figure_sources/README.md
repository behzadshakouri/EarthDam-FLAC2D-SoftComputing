# Geometry figure sources

The reference files preserve the cross-section and numerical grid used to
document the model lineage. `amin_cross_section_monitoring_grid.jpg` is the
clean author-review redraw based on the Task 2 DWG. The older PNG exports are
retained for provenance. All are adapted from the authors' earlier coupled
numerical--soft-computing study and require that citation in the caption.

`generate_task4_geometry_scale_figure.m` removes the draft marker layer,
reconstructs the ten extraction locations from the Task 2 DWG, and crops the
review redraw to the engineering section and grid. It uses labeled magenta
diamonds, rather than the teal circles in Task 3, and adds a separate nested
common-axis comparison of the four modeled geometric scale factors. This
scale-focused composition is distinct from the full monitoring plate used for
Task 3. The outlines compare discrete configurations; they do not add
measurements or imply interpolation between scale factors.
